# XV6 Project Report

This folder contains the complete LaTeX project report documenting the XV6 Operating System Enhancements.

## Files

- `XV6_PROJECT_REPORT.tex` - Complete LaTeX document with all features documented
- `images/` - Screenshots and visual documentation of all implemented features

## Compilation

To compile the report:

1. Upload both files to Overleaf or use local LaTeX installation
2. Compile with pdflatex (run twice for proper cross-references)
3. The report includes comprehensive documentation of all enhancements

## Contents

The report covers:
- User Authentication System
- File Permission Management
- MLFQ Scheduler Implementation
- Enhanced Shell Features
- Process Monitoring Tools
- Complete testing results and analysis
