FEATURE 1: CLEAR COMMAND
================================================================================

DESCRIPTION:
------------
Built-in command to clear the terminal screen, similar to Unix `clear` command.

USAGE:
------
admin$ clear

BEHAVIOR:
---------
- Clears all text from the screen
- Moves cursor to top-left corner
- Uses ANSI escape codes: \033[2J\033[H
- Works immediately (no fork/exec needed)

EXAMPLE:
--------
admin$ ls
rw-- file1.txt    uid:1 2 24 12
rw-- file2.txt    uid:1 2 25 15
admin$ clear
(screen clears)
admin$ _

TECHNICAL DETAILS:
------------------
- Implemented as built-in command in sh.c
- Uses ANSI escape sequence: ESC[2J (clear screen) + ESC[H (home cursor)
- No external program needed
- Instant execution

================================================================================
FEATURE 2: COMMAND HISTORY
================================================================================

DESCRIPTION:
------------
Stores the last 10 commands and allows navigation using arrow keys.

CAPACITY:
---------
- Stores up to 10 commands
- Oldest commands are overwritten when buffer is full
- Empty commands and duplicates are not stored

NAVIGATION:
-----------
- UP ARROW (↑)   - Go to previous command
- DOWN ARROW (↓) - Go to next command (or clear if at end)

EXAMPLE SESSION:
----------------
admin$ whoami
admin (uid: 1)

admin$ echo "test" > file.txt

admin$ ls
rw-- file.txt    uid:1 2 24 5

admin$ cat file.txt
test

admin$ <press UP arrow>
admin$ cat file.txt  # Previous command appears

admin$ <press UP arrow>
admin$ ls  # Command before that

admin$ <press DOWN arrow>
admin$ cat file.txt  # Back to more recent command

TECHNICAL DETAILS:
------------------
- History buffer: static array of 10 strings (100 chars each)
- Circular buffer implementation
- History persists during shell session
- Lost when shell exits (not saved to disk)

ESCAPE SEQUENCES:
-----------------
- ESC[A = Up arrow
- ESC[B = Down arrow
- Detected as: 27 (ESC), '[', 'A' or 'B'

================================================================================
FEATURE 3: HISTORY COMMAND
================================================================================

DESCRIPTION:
------------
Built-in command to display all commands in history.

USAGE:
------
admin$ history

OUTPUT FORMAT:
--------------
Each line shows: <number> <command>

EXAMPLE:
--------
admin$ whoami
admin$ echo "test" > file.txt
admin$ ls
admin$ cat file.txt
admin$ history
1  whoami
2  echo "test" > file.txt
3  ls
4  cat file.txt
5  history

TECHNICAL DETAILS:
------------------
- Shows up to last 10 commands
- Commands numbered sequentially
- Includes newlines from original commands
- Implemented as built-in in sh.c

TECHNICAL NOTES:
================================================================================

ESCAPE SEQUENCE HANDLING:
-------------------------
Arrow keys send 3-byte sequences:
- ESC (27) + '[' (91) + 'A' (65) = Up
- ESC (27) + '[' (91) + 'B' (66) = Down

The code detects ESC, then reads the next two characters to determine
which arrow key was pressed.

ANSI ESCAPE CODES:
------------------
- \033[2J  = Clear entire screen
- \033[H   = Move cursor to home (top-left)
- \b       = Backspace (move cursor left)

CIRCULAR BUFFER:
----------------
History uses modulo arithmetic:
- index = history_count % HISTORY_SIZE
- Automatically wraps around when full
- Oldest commands overwritten
